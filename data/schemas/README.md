# Canonical Schema Definitions

**Directory:** `data/schemas/`  
**Purpose:** Canonical JSON schemas defining the contracts for Evidence Foundation records, Operational Events, Decision Revisions, and Synchronization DTOs.

---

### Schemas
* `operational_event.schema.json`: Schema contract for near-real-time streaming events (Phase 9C-B).
* `evidence_record.schema.json`: Schema contract for Evidence Foundation units (Phase 2A).
* `nirnay_card.schema.json`: Schema contract for deterministic decision output cards (Phase 8).
* `decision_revision.schema.json`: Schema contract for immutable decision revisions (Phase 9C-D).
