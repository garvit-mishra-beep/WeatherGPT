# Reference Data Tables

**Directory:** `data/reference/`  
**Purpose:** Agronomic lookup tables, FAO-56 crop coefficient curves, and static spatial boundary constants used by VAYUBODHAK analytical engines.

---

### Reference Categories
* **Agronomic Coefficients**: Crop coefficients ($K_c$) for wheat, mustard, chickpea, paddy, and pearl millet.
* **Soil Water Depletion**: Root zone depth and total available water thresholds.
* **Spatial Baselines**: District bounding boxes and centroid coordinates for Indian administrative sectors.
