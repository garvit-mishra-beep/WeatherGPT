# LLM Tool-Calling Framework (`app/tool_calling/`)

## 1. Purpose
Orchestrates multi-round LLM tool-calling reasoning loops, converts tool definitions to provider schemas, validates LLM tool requests, and executes tools asynchronously.

## 2. Responsibilities
- Convert internal `ToolDefinition` objects into OpenAI-compatible JSON function calling schemas.
- Validate and sanitize tool calls generated by LLMs before execution.
- Manage iterative multi-round conversation loops between the LLM and the Tool Gateway.
- Enforce hard loop limits (`max_rounds=5`) to prevent infinite recursion.
- Execute concurrent tool calls using `asyncio.gather()`.

## 3. Important Files
- `framework.py`: `LLMToolCallingFramework` managing multi-round loop execution and concurrency.
- `schema.py`: Tool schema converter (`tool_to_function_schema`).
- `validator.py`: `ToolCallValidator` verifying tool names, required arguments, and JSON parsing.
- `adapter.py`: Tool calling adapter converting raw provider formats.
- `models.py`: Step-by-step loop trace models and results.

## 4. Invariants
- Direct execution bypass prohibited: All tool invocations must be dispatched through the validated `tool_executor` callback (Tool Gateway).
- Malformed tool arguments or invalid JSON are captured safely without raising unhandled exceptions.
